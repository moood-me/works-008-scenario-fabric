# Сценарии, вторая версия

Начато 2026-10-30. Здесь ведём новый подход к сценариям игр по книгам — после того, как стало видно, что первый
(«серые выборы» поверх линии книги) не даёт интересной игры.

- [principles.md](principles.md) — к чему пришли и почему: неравенства, которым подчиняется сценарий, где выбор
  интересен (как в Detroit: Become Human), и что это значит для книг.
- [reviews.md](reviews.md) — как проверяется сценарий: два ревьюера, «Игра» и «Люди», и что из ревью первой версии
  осталось верным (без повторов principles.md).

Прежние правила — `moood-me/moood:docs/writing/` (стадии, ревью, серые выборы, драма); они не отменены, но
`principles.md` спорит с некоторыми их пунктами и говорит, с какими.
